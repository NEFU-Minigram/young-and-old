##🏕️ 适老与儿童友好 AI 伴游助手 (Young-and-Old)

> 一款基于 DeepSeek 大模型与微信云开发的智能双人格伴游小程序。针对“老年人出游易累迷路”与“儿童出游易无聊走失”两大痛点，提供专属的双人格路线调度与趣味导览服务。

📖 项目背景
在旅游出行中，不同年龄段的群体面临着截然不同的痛点：
- **老年人**：体力有限，需要清晰的无障碍路线、密集的休息点与卫生间指引。
- **儿童**：注意力容易分散，需要趣味性的互动引导，同时家长需要时刻防范儿童走失。

本项目依托大语言模型（LLM）与 RAG（检索增强生成）技术，打造了**双人格智能助手**：
1. **Old 助手（慢路线调度员）**：专注适老化出行，拆解短行程，标记休息区与无障碍入口，提供大字、慢节奏的贴心陪伴。
2. **Young 助手（小任务领队）**：专注儿童友好出行，将景点讲解化作互动小任务，标记母婴室，关注防走失预警。

## ✨ 核心功能

- **🧠 双人格独立记忆**：基于云数据库实现长期记忆。Old 与 Young 的对话数据物理隔离，重新进入小程序依然记得之前的对话上下文。
- **⚡ 极速真·流式输出**：摒弃传统的“等待全部生成后一次性显示”，采用 SSE (Server-Sent Events) 技术，实现文字像打字机一样逐字显现，带来极致的丝滑体验。
- **📚 专业知识库 RAG 检索**：在前端提问时，后端云函数自动从云端数据库匹配对应的适老/儿童伴游专业知识（如：沿途休息点、母婴室位置），并注入大模型 Prompt 中，确保回答准确不幻觉。
- **🎨 沉浸式 UI/UX**：内置全局转场动画、打字机等待特效（三个点跳动），采用极高对比度的聊天气泡设计。

## 🏗️ 技术架构

本项目采用 **前后端分离 + Serverless 架构**，安全且高可用：

- **前端**：微信小程序原生开发（WXML/WXSS/JS），单页面（SPA）架构，无路由跳转卡顿。
- **后端（核心大脑）**：腾讯云开发 **HTTP 云函数** (Node.js 20)。
- **大模型**：DeepSeek API (deepseek-chat)。
- **数据存储**：微信云开发文档型数据库。

### 🛡️ 架构安全亮点（答辩必吹）
1. **彻底隐藏 API Key**：大模型的请求鉴权完全封装在 HTTP 云函数中，前端只负责收发消息，杜绝了 API Key 被反编译盗用的风险。
2. **突破超时限制**：利用 HTTP 云函数配合 `scf_bootstrap` 常驻进程，完美解决了普通云函数 3 秒超时无法输出长文本的致命缺陷，支持长达数千字的流式输出。
3. **流式数据透传**：云函数作为代理层，将 DeepSeek 官方返回的 `event-stream` 数据流实时转发给前端，实现了几乎零延迟的交互。

## 🚀 本地运行指南

1. 克隆本仓库代码到本地，使用微信开发者工具导入。
2. 在微信开发者工具中开通云开发环境，获取环境 ID。
3. 在 `pages/index/index.js` 中，将请求的 `url` 替换为你部署好的 HTTP 云函数网关地址。
4. 部署云端资源：
   - 在云开发控制台新建数据库集合：`chat_history`（用于聊天记忆）、`knowledge`（用于知识库）。
   - 在云开发控制台新建 HTTP 云函数，将 `cloudfunctions/chatServer/index.js` 内容粘贴部署，并配置 `scf_bootstrap`。
   - 替换云函数中的 `DEEPSEEK_API_KEY` 为你的真实密钥。
5. 点击编译，即可在模拟器或真机中体验。
